# Blog Application

A simple blog application built with **FastAPI** and **SQLAlchemy**. It allows users to view blog posts, read individual posts, and view posts by a specific user.

The application uses an asynchronous database connection, Jinja2 templates for HTML pages, and static and media files for frontend resources.

### Features
- View all blog posts and individual posts.
- View posts by a specific user.
- Login, registration, and account pages.
- REST APIs for users and posts.
- Custom error handling for API and web requests.
- Automatic database table creation on startup.

### Technologies Used
Python, FastAPI, SQLAlchemy, Jinja2, and an asynchronous database connection.
